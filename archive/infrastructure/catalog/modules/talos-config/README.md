# talos-config

Generates Talos Linux machine secrets and machine configuration for a cluster.

## Description

This module creates the `talos_machine_secrets` resource (which generates the
cluster CA, etcd CA, service account key, etc.) and renders the controlplane and
worker machine configuration YAMLs.  It also produces a `talosconfig` suitable
for use with `talosctl`.

> **Security note** – `talos_machine_secrets` is stored in Terraform state in
> plaintext.  Always use a secure, encrypted remote backend (e.g. S3 with SSE,
> Terraform Cloud, etc.) when managing production clusters.

## Usage

```hcl
module "talos_config" {
  source = "../../modules/talos-config"

  cluster_name       = "ops"
  cluster_endpoint   = "https://10.10.10.10:6443"
  kubernetes_version = "1.32.0"
  talos_version      = "v1.12.6"

  extra_config_patches = [
    yamlencode({
      machine = {
        install = { disk = "/dev/vda" }
      }
    })
  ]
}

# Use the base64-encoded configs as CloudStack user_data
module "cp_vm" {
  source           = "../../modules/cloudstack-vm"
  user_data_base64 = module.talos_config.controlplane_config_base64
  # ...
}
```

## Inputs

| Name | Type | Description | Default | Required |
|------|------|-------------|---------|----------|
| `cluster_name` | `string` | Name of the Talos / Kubernetes cluster. | – | yes |
| `cluster_endpoint` | `string` | Kubernetes API server endpoint (https://\<LB_IP\>:6443). | – | yes |
| `kubernetes_version` | `string` | Kubernetes version to install. | `"1.32.0"` | no |
| `talos_version` | `string` | Talos Linux version (e.g. v1.12.6). | `"v1.12.6"` | no |
| `control_plane_count` | `number` | Number of control plane nodes (informational). | `1` | no |
| `worker_count` | `number` | Number of worker nodes (informational). | `1` | no |
| `install_disk` | `string` | Block device path for Talos installation. | `"/dev/vda"` | no |
| `pod_subnet` | `string` | CIDR block for pod networking. | `"10.244.0.0/16"` | no |
| `service_subnet` | `string` | CIDR block for Kubernetes service networking. | `"10.96.0.0/12"` | no |
| `extra_config_patches` | `list(string)` | Talos machine config patches (YAML strings) for controlplane. | `[]` | no |

## Outputs

| Name | Description | Sensitive |
|------|-------------|-----------|
| `machine_secrets` | Talos machine secrets object. | yes |
| `client_configuration` | Talos client configuration object (ca, crt, key). | yes |
| `controlplane_config` | Controlplane machine configuration YAML. | yes |
| `worker_config` | Worker machine configuration YAML. | yes |
| `talosconfig` | Talosconfig YAML for talosctl. | yes |
| `controlplane_config_base64` | Controlplane config encoded as base64 (for CloudStack user_data). | yes |
| `worker_config_base64` | Worker config encoded as base64 (for CloudStack user_data). | yes |
| `cluster_endpoint` | Kubernetes API server endpoint. | no |

## Important Notes

- **Machine secrets in state**: The PKI material generated by `talos_machine_secrets`
  is stored in Terraform state.  Treat state files with the same care as private keys.
- **Immutable secrets**: Once created, machine secrets should never be regenerated
  unless the cluster is being rebuilt from scratch.  Use `lifecycle { prevent_destroy = true }`
  on the `talos_machine_secrets` resource in production.
- **Patches**: `extra_config_patches` only applies to the controlplane config.
  Pass worker-specific patches via a separate module invocation if needed.
